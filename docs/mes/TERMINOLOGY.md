# Terminologie

D89 T01–T10. Applicatie MES; portalen Production Execution, Manufacturing Operations, Planning, Quality, Process Engineering, Traceerbaarheid, Maintenance, Management, Systeembeheer, Wandschermen. Nederlandse schermteksten waar begrijpelijk, gekozen Engelse namen behouden. Bestaande DB/API Nederlands, nieuwe domeinen Engels. PS1–PS18 behouden en later classificeren.

| Begrip | Betekenis |
|---|---|
| Master Recipe | ISA-88 receptdefinitie |
| MBR | Master Recipe plus registratie- en kwaliteitseisen |
| Control Recipe | Concrete batch/lot uitvoeringsdefinitie |
| EBR | Electronic Batch Record, werkelijk uitgevoerd |
| Production Order | Hoeveelheid en behoefte |
| Job Order / Response | Werkopdracht / werkresultaat |
| Dispatching | Expliciete werkvrijgave |
| Equipment / Physical Asset | Functionele eenheid / fysieke installatie |
| Material Definition / Lot / Sublot | Materiaaldefinitie / partij / deelpartij |
| Batch / lot | Fabriekseigen afzonderlijke uitvoering / samengesteld product |
| Procedure / Unit Procedure / Operation / Phase | Procedure / deelprocedure / bewerking / handeling |
| Setpoint / Actual | Gewenste instelling / gemeten waarde |
| Doelwaarde / bedrijfstolerantie / proceslimiet / specificatiegrens / statistische regelgrens | Vijf afzonderlijke categorieën; veiligheidslimieten buiten MES |
| OOS / OOT | Buiten specificatie / buiten trend |
| Deviation / nonconformance | Afwijking / niet-conformiteit |
| Hold / disposition / release | Blokkade / kwaliteitsbesluit / vrijgave |
| CoA / CAPA / RCA | Analysecertificaat / corrigerende en preventieve maatregelen / grondoorzaakanalyse |
| OEE / FPY / SPC / Cpk / WIP | Prestatie-indicatoren; definities vóór implementatie vastleggen |

Een route is pas een MBR wanneer de volledige vereisten aanwezig zijn. Geen automatische hernoeming van incomplete functies.
